# Alpha Labs Playmaker V4.4

This release replaces V4.3's partial visual cleanup with a unified, minimal portrait design across match setup, hero placement, opening hand, battle, and discard selection. It retains the V4.3 gameplay engine, AI, private login, and installable PWA.

## Changes
- Cohesive dark green panels, lime highlights, muted purple Play cards, restrained typography and spacing. No new decorative illustrations.
- Cleaner setup and placement screens with redundant instruction banners removed.
- Battle header, counters, active cards, bench and scoring panels restyled for portrait.
- Play hand remains a single overlapping row. Used Plays remain under their hero.
- Required card discards open a full-screen, vertically listed picker with individually tappable choices; the existing discard functions process selections.
- No separate card number controls or Play-description panels beneath the hand.
- The Ready for Battle screen stays skipped by the game engine.

## Deployment
Deploy the **contents** of this ZIP to the existing Vercel project, preserving the existing `ALPHA_APP_PASSWORD` and `ALPHA_SESSION_SECRET` environment variables. No PWA reinstall is necessary. Refresh or fully close and reopen the installed app to load the new CSS/JS.

## Verification scope
JS syntax and ZIP integrity checked. The live deployment and iPhone-specific interactions have not been end-to-end tested; verify a Play-discard and Hero-discard effect after deployment.
