# Alpha Labs Playmaker V4.6

Portrait battle geometry fix. All three columns are strictly constrained, with no transforms or absolute hero positioning allowed. Hero cards scale to their grid cells; bench remains independent. Play cards remain a single overlapping row and selected cards rise to the front. Redundant play-phase instructions are hidden on portrait mobile.

Game engine, AI, authentication, desktop presentation, and PWA settings remain unchanged from V4.5.

Deploy all ZIP contents to the existing Vercel project. Test on iPhone in portrait; this build has not been browser-tested on a physical device.
